# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version.

## Reporting A Vulnerability

Do not report suspected vulnerabilities in a public issue. Use GitHub private vulnerability reporting for this repository so the report and any supporting material remain private while it is investigated.

Terraform state can contain rendered Zoom Node registration codes and passwords. Store state in an encrypted, access-controlled backend and never attach state or plan files to public reports.
